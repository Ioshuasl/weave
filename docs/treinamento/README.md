**Fonte única:** estes arquivos são o texto oficial. A plataforma mostra o mesmo conteúdo em **Treinamento**
(uma aula por seção `##`). Depois de editar um guia, atualize a plataforma com:

```bash
cd backend && npm run seed:training
```

O script é repetível: atualiza as aulas existentes pelo título e despublica as que saíram do arquivo.

Os vídeos (Remotion + Playwright + Kokoro + FFmpeg) seguem estes textos: ver `../fase-6-videos-remotion.md`.
